# 阶段 0 资源预检说明

脚本 `scripts/phase0_preflight.py` 用于真实验证开始前检查资源是否到位。它不属于主产品运行时代码，也不会打印密钥值、音频文件名、音频正文或模型内容。

## 使用方式

在工作区根目录执行：

```powershell
py -3.12 scripts/phase0_preflight.py
```

资源到位后，可以指定临时目录：

```powershell
py -3.12 scripts/phase0_preflight.py `
  --audio-dir D:\Temp\authorized-audio `
  --laya-dir D:\Temp\laya-weights `
  --require-feishu
```

脚本只输出飞书环境变量的数量、音频数量/总大小和权重数量/总大小。环境变量值必须通过密码管理器或本机临时环境注入，不能写入仓库。

## 解释输出

- `feishu_status=PENDING`：没有完整测试凭证，不能开始真实 V-02；
- `audio_status=...`：文件存在不等于获得授权，仍需确认四类样本和脱敏范围；
- `laya_status=...`：有权重不等于可用，仍需确认权重许可、中文标注样本、校准和资源占用；
- `--require-feishu` 只在四个飞书环境变量都存在时返回成功，不验证租户权限，也不会发起网络请求。

该预检通过后，仍必须按 `docs/阶段0-真实验证执行手册.md` 执行真实接口和样本验收。
