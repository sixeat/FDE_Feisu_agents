# 阶段 0 用户准备清单

这份清单用于解除阶段 0 的外部资源阻塞。资源只用于自己的飞书测试企业和本地临时验证，不要把密钥、原始录音、完整群消息或完整文档正文发到聊天或提交 Git。

## 一、最优先：飞书测试环境

### 账号和应用

- [ ] 自己可管理的飞书企业测试租户；
- [ ] 一个企业自建应用；
- [ ] 应用已开启机器人能力；
- [ ] 已配置事件订阅和卡片动作回调；
- [ ] 已配置网页应用能力（只需能配置，H5 暂时不必开发）；
- [ ] 一个本机可用的回调地址，例如临时公网隧道；
- [ ] 应用的 `app_id`、`app_secret`、`encrypt_key`、`verification_token` 已放在本机环境变量或密码管理器中。

密钥只需要在本机使用，不需要发给我。后续记录只保存“变量是否存在”和脱敏后的错误类别。

### 测试成员和资源

- [ ] 测试用户 A：提交任务或上传测试文件；
- [ ] 测试用户 B：模拟被分配任务的成员；
- [ ] 测试管理员：点击人工确认按钮；
- [ ] 一个只加入上述成员和机器人的测试群；
- [ ] 一个专门创建的虚构会议纪要文档或文件；
- [ ] 一个可以删除或归档的测试任务空间。

测试内容不要包含真实客户、同学、公司员工的个人信息。文档可以写成“项目 Alpha 会议”，责任人使用虚构姓名或测试成员。

### 第一轮建议的最小权限

先申请能够完成以下动作的最小权限：

1. 接收测试群内 `@机器人` 事件；
2. 发送机器人消息和交互卡片；
3. 读取专用测试文档/文件；
4. 在人工确认后创建并查询一条测试任务；
5. 获取触发用户的必要身份信息。

不要第一轮申请读取全部群消息、批量知识库写入、删除文档或其他高危权限。具体 scope 名称以目标租户页面显示为准，记录名称和审批结果即可。

## 二、第二优先：飞书会议产物

准备一个由飞书生成或手工模拟的专用会议纪要/转写文档：

- [ ] 内容为虚构会议，不含真实个人信息或业务机密；
- [ ] 至少包含一个明确待办、一个缺少责任人的事项、一个含糊日期和一个决定事项；
- [ ] 能提供文档链接或 ID，并能在飞书中确认版本和访问权限；
- [ ] 如使用手工文档，明确标记为“读取/解析链路模拟”，不宣称已验证飞书自动会议产物接口。

自研录音、ASR 和说话人分离不属于当前阶段准备项，后续若重新启用再单独准备授权音频。

## 三、第三优先：Laya 评估材料（可后置）

如果希望完整评估 Laya，再准备：

- [ ] 确定的 Laya 权重来源、版本和许可证；
- [ ] 少量人工标注样本，至少覆盖“路由、补问、风险候选”；
- [ ] 每条样本的人工正确答案；
- [ ] 运行设备和可接受的延迟范围。

Laya 不是会议主链路的安全边界，也不负责最终权限或审批。如果暂时没有权重，可以先完成飞书会议产物验证，并将 Laya 记录为延期或采用规则/LLM 基线。

## 四、目前不需要准备

- 不需要部署公网生产服务器；
- 不需要购买 Kubernetes 或云 GPU；
- 不需要准备真实企业生产数据；
- 不需要同时安装 Hermes 和 OpenClaw；
- 不需要先做 Docker Compose；
- 不需要把任何密钥、录音或完整文档发给我。

## 五、准备完成后的执行顺序

```text
本机设置测试环境变量
→ 运行 phase0_preflight.py
→ V-02：读取测试文件
→ V-02：发送卡片并验证回调
→ V-02：人工确认后创建一条测试任务并对账
→ V-06：读取会议纪要/转写文档并验证来源与版本
→ V-04：有权重和标注样本时再评估 Laya
→ 更新阶段 0 出口评审
```

你只需要先准备飞书测试资源和一个专用会议产物；Laya 材料可以最后决定是否投入。
