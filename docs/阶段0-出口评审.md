## 3. 阶段 0 仍需的外部输入

这些输入不应通过聊天发送密钥或个人数据，只需在本地临时环境使用，并在记录中保留脱敏结果：

1. 一个自己的飞书测试企业、自建应用、测试用户和测试群；应用至少开启机器人事件、卡片回调所需配置。
2. 一个专用测试文件和可删除/归档的测试任务空间；需要管理员确认最小 scope。
3. 一个可访问回调地址，或在本地运行临时隧道；只记录验签结果和脱敏事件摘要。
4. 一个专用的飞书会议纪要/转写文档，内容为虚构会议，能够验证来源位置、版本和权限。
5. Laya 真实权重的来源、版本和许可确认，以及少量人工标注的路由/补问/风险样本；Laya 可后置。

## 4. 阶段 0 通过后的动作

只有上表的“待验证”项都有独立证据，才把阶段 0 标为“已完成”，并进入阶段 1 的领域模型和最小控制平面设计。V-03 ASR 属于后置扩展，不再作为第一版或阶段 0 的出口条件。若任一当前范围内的外部能力失败，必须先写入降级方案：

- 飞书文件或任务接口不满足：先用本地脱敏夹具验证控制平面，真实写入延期；
- 飞书会议产物接口不稳定：接受文字纪要上传或 H5 粘贴会议结果；
- Laya 无收益：移除 Laya，使用规则 + LLM 结构化输出；
- Hermes 控制或隔离不足：Runtime 降级为无凭证短任务，或暂不接入业务工具。
